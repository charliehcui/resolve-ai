# Recover a failed report export

Report exports prepares a downloadable report in the background. The latest result appears in Recent activity.

If Report exports is disabled, open Settings, select Report exports, enable it, and request one export.

If your account is active, Report exports is already enabled, and the latest export failed, there is no confirmed customer-side recovery step. Do not repeatedly request the same export. Contact support so they can inspect the existing operation without asking you for internal records.

Customer guidance does not execute or confirm an internal retry.
