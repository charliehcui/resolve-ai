# Recover missing order notifications

First confirm that Order notifications is enabled and that the saved destination address is correct.

Save the destination again, then send one test notification. Check Recent activity for the new result.

If the test succeeds, the destination is working again. If it fails, stop repeating the test and contact support with the approximate test time. Support can continue the investigation without asking you for technical logs.
