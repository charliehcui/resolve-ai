# Version 2026.8

ResolveLab version 2026.8 shows order notification settings under Settings, then Order notifications.

The version includes a Recent activity page with the latest delivery result and time. Older instructions that refer to Notification history do not match version 2026.8.

Use the instructions for version 2026.8 when checking the feature or following recovery steps.
