# Quick checks for missing order notifications

If an order notification does not arrive, complete these checks:

1. Open Settings and confirm that Order notifications is enabled.
2. Confirm that the destination address is the address your team currently uses.
3. Open Recent activity and check the result of the latest notification.
4. Send a test notification and check whether a new result appears.

If the test also fails, keep the time of the test and contact support. You do not need to collect technical logs.
