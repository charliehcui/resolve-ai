# Order notifications overview

ResolveLab can send an order notification when an order changes, such as when an order is completed.

Order notifications must be enabled before ResolveLab can send them. The account must also be active.

The Recent activity page shows whether the latest notification was sent successfully or failed. A failed notification does not mean that the order update was lost. It means the destination did not accept that notification.
